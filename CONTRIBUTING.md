# Участие в разработке

Обсуждения ошибок и предложений — в [GitHub Issues](https://github.com/lawlabs/rosreestr-xml-viewer-winui/issues).

## Локальная проверка

Требуются Windows, .NET 10 SDK, инструменты WinUI и WinApp CLI 0.7.1+. Настройка и запуск описаны в [README](README.md).

```powershell
dotnet build .\RosreestrViewer.csproj -c Release -p:Platform=x64
dotnet run --project .\Tests\RosreestrViewer.Core.Tests.csproj -c Release
winapp run .\RosreestrViewer.csproj --detach --json --args '--test-profile'
```

Для изменений интерфейса проверьте реальное окно, светлую и тёмную темы. UI-сценарии из `scripts/ui-*-tests.ps1` запускаются с PID отдельного тестового окна. Не направляйте автоматизацию на окно с личными документами.

## Примеры и отчёты об ошибках

- Не прикладывайте настоящие выписки, подписи, персональные данные или ссылки с токенами в Issues, PR и коммиты. Маскировки одного ФИО недостаточно: адреса, номера, подписи, координаты и идентификаторы также могут раскрывать сведения.
- Для отчёта обычно достаточно корневого XML-элемента, namespace, версии, текста ошибки и последовательности действий. Для воспроизведения подготовьте минимальный синтетический XML с вымышленными данными и без исходной электронной подписи.
- В `Samples/` хранятся только вымышленные примеры; они не являются официальными образцами XSD. `.gitignore` исключает XML вне `Samples` и `Templates`, PDF, архивы и подписи. Это защита от случайного добавления, а не проверка содержимого.
- Не добавляйте `artifacts/`, `bin/`, `obj/`, профили WebView2, сертификаты или настройки пользователя. Отчёты и снимки экрана создавайте в `artifacts/` локально.

## Шаблоны и ресурсы

`Templates/Archive/` проверяется по SHA-256 из каталога. Не форматируйте эти файлы и не меняйте их окончания строк или кодировку. Новый шаблон должен иметь подтверждённый источник, условия распространения, версию, namespace и синтетический пример. См. [описание каталога](Templates/SOURCES.md) и [сторонние материалы](THIRD_PARTY_NOTICES.md).

Проект собирается из уже включённого каталога: импорт из старого Delphi-проекта не нужен для обычной сборки. Для сознательного обновления снимка передайте `scripts/import-legacy-templates.ps1 -LegacyProject <путь>`.

Исходники значка и команда генерации размеров описаны в [Assets/Branding/README.md](Assets/Branding/README.md).

## Pull request

Опишите проблему, получившееся поведение и проведённую проверку. Для исправления парсера или сравнения добавляйте проверку реального сбоя на синтетических данных. Для косметических изменений достаточно сборки и визуальной проверки. Собственный вклад в код предоставляется на условиях MIT; сторонние материалы сохраняют свои условия.
