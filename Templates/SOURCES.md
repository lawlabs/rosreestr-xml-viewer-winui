# Пакеты печатных форм

Снимок восстановлен из `RosreestrXMLViewer/Resources/XLT/XSLRC` предыдущего Delphi-проекта. В составе только непустые XSL и используемые справочники XML/XSD; выписки и персональные данные сюда не копируются. Повторяемый импорт: `scripts/import-legacy-templates.ps1 -LegacyProject <путь>`. Он не требуется для сборки: снимок уже включён в репозиторий. Файлы сохраняют исходные байты, адрес и SHA-256 записаны в `catalog.json`. [уведомления об источниках](../THIRD_PARTY_NOTICES.md).

Для сторонних XSL нет подтверждения полноты относительно каждой редакции современного XML. Они явно обозначены в интерфейсе. Произвольный namespace, другая версия `Extract` или неизвестная ссылка `xml-stylesheet` не подменяются подходящим по названию шаблоном.

В кэше есть пустые `Common.xsl` для `EGRP_FIR/Reestr_Extract_Object/03` и `Reestr_Extract_Gkn/OKS/07`. Первый пакет не объявляется поддержанным. Для второго в каталоге явно задан совместимый пакет `KPOKS 4.0.1` из `Reestr_Extract_Big/ROOM/07`; при использовании этой связи интерфейс предупреждает, что исходный XSL не сохранился и точное совпадение не подтверждено.

Отсутствующие относительные копии справочников сопоставлены с единственной побайтно одинаковой копией того же имени в архиве. Эти связи отражены отдельными `alias` в каталоге. Папка `ZU` на диске называется `Land`, поскольку MSIX PRI воспринимает `ZU` как языковой квалификатор зулу; исходные URL и содержимое файлов сохранены.

## Воспроизведение

`XslCompiledTransform` выполняется в .NET, WebView2 получает уже готовый HTML. Нужна обычная JIT-сборка; Native AOT не заявляется. Зависимости `include`, `import` и `document()` разрешаются исключительно в проверенном снимке. Доступа к сети или файлам вне него у XSL нет. DTD исходного XML запрещён; небольшие внутренние сущности допустимы только в проверенных XSL. Выход ограничен 16 МБ.

Таблицы, объединённые ячейки, текст и CSS сохраняются. Для `Reestr_Extract_List/07` адаптирован `rowspan=0`: IE8 трактовал его как одну строку, HTML5 — как все оставшиеся строки. Это изменение выполняется в результате преобразования, исходный XSL и XML не редактируются. Доступные изображения из вложений включаются в HTML как `data:`; отсутствующие отмечаются.

JavaScript старых шаблонов не исполняется. Поэтому их интерактивные графические построения не воспроизводятся; это отмечается рядом с формой. Готовые планы доступны во вложениях, самостоятельные построения по координатам — во вкладке схемы. Печатная форма остаётся на белой бумаге при тёмной теме оболочки. Разбивка страниц Chromium может отличаться от IE и PDF Росреестра. Совпадение с исходным PDF гарантируется только при показе и сохранении самого файла без преобразования.
