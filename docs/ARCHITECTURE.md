# Архитектура и границы реализации

## Слои

- `Core/ExtractParser.cs`: XMLReader с сохранением исходных байтов, namespace-независимые имена элементов, распознавание известных семантических разделов, полное дерево полей с индексами повторяющихся узлов. Отдельная обработка старых объектов GKN и уведомлений. Карточка не достраивает неизвестные справочные значения предположениями.
- `Core/ImportService.cs`: XML, PDF и ZIP, привязка вложений/подписей, ограничения ресурсов и ошибки по отдельным файлам. Повреждённый документ не отменяет чтение соседнего. Каждый импорт асинхронен и отменяем; отдельный XML парсится целиком до проверки следующего файла.
- `Core/GeometryRenderer.cs`: локальная схема SVG, каталоги точек, расчёт замкнутых колец. В просмотре неизвестные независимые системы разделяются; экспорт SVG предлагает выбор системы при наличии нескольких.
- `Core/ReportRenderer.cs`, `RegistryService.cs`: краткий читаемый отчёт, CSV, извлечение номеров и сравнение полей. Это отдельное представление для анализа.
- `Core/PrintFormService.cs`: версионный каталог XSL, SHA-256 ресурсов, локальный ограниченный resolver, преобразование исходного XML в .NET. AngleSharp сохраняет табличную структуру и CSS, удаляет активное содержимое, встраивает доступные изображения. Оформление не проходит через карточку и не зависит от браузерного XSLT. Разрешены только пакеты из каталога; неизвестные версии и ссылки не заменяются карточкой.
- `Core/GraphicDownloadService.cs`: явная загрузка HTTPS-графики с официальных доменов, лимиты и кэш по хэшу URL. Внутренние ссылки серверов не превращаются в публичные URL.
- `Core/SchemaValidationService.cs`: проверка XML по выбранному локальному пакету XSD; неизвестный корень и ошибки/предупреждения не выдаются за полную успешную проверку.
- `MainWindow`: штатный TitleBar, Mica, размер с учётом DPI, Frame.
- `MainPage` и partial-файлы: координация UI, выбор файлов, выборка, системные диалоги, отдельный каталог предпросмотра. Бизнес-обработка находится в Core. `DocumentListItem` — граница между неизменяемыми объектами ядра и XAML-метаданными.
- `MainPage.Printing.cs`: просмотр и экспорт формы, список связанных PDF, подготовка печати A4. PDF из пакета копируется без преобразования; пакетная печать XSL сохраняет отдельные файлы с дедупликацией по хэшу исходника. Сессия хранит также пути повторно импортированных одинаковых XML, чтобы при восстановлении повторно найти их вложения.

## Осознанные ограничения

Это работающая первая версия нового приложения, а не сертифицированный универсальный декодер ЕГРН. Проверка на больших реальных наборах не подтверждает полной поддержки всех схем, юридической силы отчёта, криптографической подписи или доступности сервисов Росреестра. В составе проекта есть воспроизводимые проверки и конкретные пределы.

Для развития нужны следующие самостоятельные этапы:

1. **Расширение версионного каталога.** Имеющийся архив из восьми XSL-пакетов описан в `Templates/SOURCES.md`. Нужны подтверждённые действующие XSD/XSL с датой введения, новыми обезличенными примерами и визуальной сверкой каждой редакции с официальным PDF. Совпадение структуры таблиц ещё не гарантирует совпадения всех полей и страниц.
2. **Постоянный большой каталог.** SQLite-индекс, импорт потоками, раздельное хранение файлов и метаданных, ленивый разбор выбранной выписки. Текущая сессия хранит открытые документы в памяти и намеренно ограничивает разовый импорт.
3. **ГОСТ-подписи.** Интерфейс независимого криптопровайдера, CryptoPro/сертифицированный стек, проверка содержания, цепочки доверия, статуса отзыва и времени. Состояния: найден файл, проверка недоступна, подпись неверна, криптографически корректна, доверие подтверждено. Ни одно из этих состояний нельзя заменять наличием файла SIG.
4. **Кадастровая геометрия.** Интерпретация признаков замкнутости и типов пространственных единиц по схеме, отверстия, составные контуры, точечные/линейные объекты, диагностика самопересечений; параметры МСК и подтверждённая проекция. Отдельные планы помещений и этажей сохраняются как документальные изображения.
5. **Официальная интеграция.** Только документированные и разрешённые механизмы получения результатов услуги, учёт авторизации/срока ссылок, лицензирования и ограничений НСПД. Произвольный scraping внутренних endpoint не должен становиться обязательным для локального просмотра.
6. **Выпуск.** Подписанный MSIX, лицензия/метаданные издателя, обновления, файловые ассоциации, локализация ресурсами, аудит доступности с Narrator/High Contrast, проверка установки на чистой системе. Текущий проверенный способ запуска — разработческий packaged-запуск через WinApp CLI.

Приоритет следующего этапа определяется реальными ошибками извлечения из пользовательского набора: сначала корректность отдельных семейств и дисковый каталог, затем криптографическая проверка и точная кадастровая геометрия.
