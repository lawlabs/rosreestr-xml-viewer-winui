# Проверка реализации

Основной проход: 15 октября 2026 года; подготовка публичного репозитория — 16 октября 2026 года. Указанные ниже файлы `artifacts/` являются локальными результатами проверки и в Git не включаются.

Перед первой публикацией проверена отдельная чистая копия содержимого Git: Release x64 собран без ошибок и предупреждений, все 65 проверок прошли. При Windows-настройке `core.autocrlf=true` все 82 записи каталога сохранили исходные SHA-256. В индекс не вошли сборки, локальные отчёты, пользовательские документы, подписи и ключи; в подготовленных исходниках не найдены совпадения с проверенными шаблонами токенов и приватных ключей. Это проверка состава публикации, не исчерпывающий аудит безопасности.

- Debug x64: сборка без ошибок и предупреждений, packaged-запуск с реальным отзывчивым окном.
- 65 проверок ядра: современные и старые узлы, Windows-1251, границы, открытые контуры, права/доли, уведомления, вложения, ZIP, исходные байты, повторяющиеся записи, CSV, PDF, XSD и ограничения чтения; XSL-таблицы, объединённые ячейки, обе записи о правах, совместимость `rowspan=0`, неверные версии/ссылки, контрольные суммы и запрет сетевых зависимостей; сопоставление и сохранение PDF. Включены извлечение номеров из произвольного текста, пробелы/переносы, повторы, некорректные цепочки, ведущие нули, пересечение и обе разности, пустые и одинаковые наборы.
- 5 сценариев UI Automation для списков номеров: произвольный текст с повторами, каждый пустой список по отдельности, одинаковые наборы и отсутствие ложного номера в цепочке из пяти блоков. Все прошли; локальные результаты — `artifacts/ui-cadastral-lists/results.json`.
- 12 сценариев UI Automation в отдельном тестовом профиле: запуск, импорт, фильтр, пустая выборка, схема, поля/исходник, вложения, сравнение, смена темы, архивная печатная форма, выбор представления PDF и недоступная форма без подмены карточкой.
- Ещё 4 сценария через реальные системные диалоги: сохранение формы PDF, HTML, повторный импорт того же XML с появившимся PDF без дублирования строки, сохранение исходного PDF с совпадением SHA-256. Все прошли. Доказательства — `artifacts/ui-printing-native-final/results.json` и `artifacts/ui-print-forms-final/results.json`.
- Пакетная печать проверена через системный выбор папки: из четырёх демонстрационных XML сохранена одна поддержанная XSL-форма, три неподдержанные пропущены с явным сообщением. PDF лежит в `artifacts/ui-printing-batch`.
- Через реальные диалоги сохранения созданы CSV с тремя демонстрационными выписками и PDF с отчётом. Итоговый PDF — A4, три страницы; все страницы отрисованы Poppler и просмотрены, заголовки не отрываются от начала таблиц. Повторно проверены светлая/тёмная темы и видимость всей схемы.
- Полный повторный аудит пользовательского набора: 21264 исходных XML/ZIP; 26922 различных документов/объектов, включая 2756 самостоятельных PDF и 4979 уведомлений. Теперь PDF с другим именем не теряются в ZIP с XML: дополнительно обнаружено 716 самостоятельных PDF. Ошибки: один архив сверх лимита, 23 архива без XML/PDF, семь ошибок чтения. Подробности без персональных данных — `artifacts/corpus-audit.json`.
- Выборочная проверка печатных форм: просмотрены метаданные 4998 XML, преобразованы первые до 12 различных исходников каждого корня. Всего 84 примера, 71 форма успешно сформирована по всем восьми пакетам. Не поддержаны 12 новых уведомлений об отсутствии сведений и одна другая редакция машино-места; вместо формы показано отсутствие подходящего шаблона. Это проверка преобразования, а не полное визуальное сравнение с PDF. Обезличенный результат — `artifacts/print-form-audit.json`.
- Форма демонстрационного `Extract 07` сохранена через приложение в одностраничный PDF A4 и HTML. PDF отрисован Poppler и просмотрен; таблица с объединёнными ячейками, оба правообладателя и реквизиты расположены корректно. Форма остаётся на белой бумаге при тёмной теме оболочки.
- Официальный каталог XSD доступен напрямую с текущего компьютера. Скачан и исследован официальный KVZU v07; учтены зависимости в соседней `SchemaCommon`. Пакет компилируется; проверенная реальная KVZU из пользовательского набора получила одну диагностику и не была объявлена соответствующей XSD. Это не доказательство повреждения оригинала или универсальной применимости выбранной схемы.

Аудит чтения не подтверждает полноту семантического извлечения всех полей. Пока не проверены локальные ГОСТ-подписи, авторизованная загрузка планов Росреестра, High Contrast/Narrator и установка на чистой системе. Текущая карточка — локальное представление, а не сертифицированная официальная форма.

Проверка качества WinUI: анализатор подключён к проекту, сборка не подавляет его предупреждения. Исправлены контраст системных кнопок в тёмной теме и смешивание неизвестных систем координат при экспорте SVG. Извлечение и формирование отчётов находятся в Core; обработчики страницы координируют диалоги и представление. Длинный список виртуализирован `ListView`, внешние данные экранируются, произвольные URL не передаются системному запуску. До выпуска остаются локализация строк через ресурсы и ручная проверка доступности; это замечания к подготовке релиза, а не подтверждённые ошибки чтения документов.
