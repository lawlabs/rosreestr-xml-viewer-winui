# Сторонние материалы

Лицензия [MIT](LICENSE) распространяется на собственный код этого проекта, тесты и демонстрационные примеры. Она не заменяет условия использования сторонних материалов и зависимостей.

## Архивные печатные формы

`Templates/Archive/` — снимок XSL, XML-справочников и XSD из кэша предыдущего Delphi-приложения. Файлы сохранены без изменения содержимого. Их исходные URL, SHA-256 и связи перечислены в [Templates/catalog.json](Templates/catalog.json); происхождение и адаптации при воспроизведении описаны в [Templates/SOURCES.md](Templates/SOURCES.md).

- `portal.rosreestr.ru` — архивные шаблоны Росреестра и справочники.
- `legalcalc.ru` — архивные сторонние шаблоны.

Отдельная общая лицензия на весь этот снимок в исходном кэше не обнаружена. Корневая MIT не является разрешением от правообладателей этих файлов. Уведомления и встроенные сведения об авторах сохраняются; перед дальнейшим распространением сторонних материалов отдельно от проекта следует уточнять применимые условия у их правообладателей.

В некоторых архивных XSL также находятся JavaScript и данные шрифтов с собственными уведомлениями. Приложение сохраняет архивные байты для проверки целостности, но удаляет активное содержимое из результата преобразования и не исполняет эти сценарии. Нельзя считать отдельную MIT-пометку во встроенном JavaScript лицензией всего XSL или шрифта.

## Зависимости NuGet

Зависимости загружаются NuGet, их бинарные файлы не хранятся в Git. Условия распространяемых пакетов необходимо сохранять при подготовке установщика.

| Зависимость | Источник условий |
| --- | --- |
| AngleSharp | [репозиторий и MIT](https://github.com/AngleSharp/AngleSharp/blob/devel/LICENSE) |
| Windows App SDK / WinUI / WebView2 | [Windows App SDK](https://github.com/microsoft/WindowsAppSDK), лицензии соответствующих NuGet-пакетов |
| Windows SDK BuildTools и WinUIAnalyzer | лицензии соответствующих NuGet-пакетов Microsoft |
| Windows SDK BuildTools WinApp | [WinApp CLI](https://github.com/microsoft/WinAppCli), лицензия NuGet-пакета |

Приложение является независимым проектом. Названия Росреестра, ЕГРН и НСПД используются для обозначения форматов и сервисов; это не официальное приложение этих организаций.
